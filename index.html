# YouTube AI Agent (Starter Project) A beginner-friendly Python project that helps YouTube creators brainstorm video ideas, create a simple outline, and draft a basic script from a topic. ## Features - Generates five starter video ideas - Creates a simple video outline - Drafts an introductory YouTube script - Saves the script to `youtube_script.txt` - Works without an API key or paid service ## Requirements - Python 3.10 or newer - No third-party packages required ## How to run 1. Download or clone this repository. 2. Open a terminal in the project folder. 3. Run: ```bash python main.py ``` 4. Enter a video topic and your channel name. 5. Find the saved script in `youtube_script.txt`. On some systems, use `python3 main.py` instead. ## Project status This is a starter project. It does **not** connect to YouTube Analytics, read private channel data, publish videos, or call an AI model yet. Those features require additional setup, permissions, and/or API credentials. ## Responsible use Review, edit, and fact-check all generated content before publishing. Do not include passwords, API keys, or private channel information in public files.
